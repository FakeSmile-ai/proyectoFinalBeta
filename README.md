# ingenieria-software-proyecto

Fase 1 del curso de Ingeniería de Software, enfocado en analizar, documentar y modelar un sistema web de apuestas por ligas para el Mundial 2026. Incluye el Acta del Proyecto, Documento de Visión, Glosario, Reglas de Negocio, Módulos del Sistema, Metodología híbrida (RUP + Scrum/Kanban), Historias de Usuario con criterios de aceptación, SRS formal, Casos de Uso UML, Matriz de Trazabilidad y diagramas BPMN.
